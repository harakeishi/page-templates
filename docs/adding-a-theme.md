# デザインを追加する

## フォルダ構成

```
themes/<名前>/
├── index.html      # デザイン本体。profile.js を読み込んで描画する
├── profile.js      # サンプルの内容（yourname.dev など架空のもの）
└── screenshot.png  # 一覧に載せるスクリーンショット（1280×800 程度）
```

`<名前>` は英小文字とハイフンで付けます（例: `dig`、`terminal-mono`）。

## 決まりごと

- **フォルダ単体で動くこと。** フォルダの中身だけを静的ホスティングに置いて公開できるようにします。ほかのフォルダのファイルは参照しません。
- **ビルド不要。** HTML / CSS / JavaScript だけで動くようにします。
- **profile.js は共通形式。** [docs/profile.md](profile.md) の形式に従い、どのデザインの `profile.js` を持ってきても表示できるようにします。使わない項目は無視して構いません。
- **サンプルは架空の内容。** 実在の人の情報は入れません。
- **文章は安全に描画する。** `profile.js` の文字列を `innerHTML` に直接入れず、テキストとして扱います。リンクは `http:` / `https:` / `mailto:` などに限ります。
- **基本の品質。** スマホ幅で横スクロールが出ないこと、キーボード操作でフォーカスが見えること、ダークモードと「動きを減らす」設定に対応すること。

## 追加したら

1. ルートの `README.md` のデザイン一覧に1行追加する
2. スマホとPCの両方でブラウザ表示を確認する
3. プルリクエストを送る
